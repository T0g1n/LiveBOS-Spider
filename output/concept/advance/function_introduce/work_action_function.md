# 执行流程动作函数：LB_workAction(流程表单,ID,动作ID,摘要说明)

---

执行流程动作函数：LB\_workAction(流程表单,ID,动作ID,摘要说明)

该函数可以在表达式中，对于流程表单中对应ID记录执行一个对应的工作流节点的动作。

流程表单：字符串类型，不能为空。指对应的工作流表单的对象名。

ID：数值型，不能为空。指流程表单对应记录的ID值，如果该记录中流程实例值小于0，则代表该记录没有对应流程任务，笨函数将自动启动一个流程任务，并将流程实例值绑定于该记录中。

动作ID：数值型，对应流程中动作的ID值，当该值小于0时代表不执行流程动作。一般常见于启动流程。当是合法的值时将执行对应流程动作，并引发流程转向就流程事件处理等。

摘要说明：字符串类型，填入流程步骤明细中摘要信息的内容。
